# 🌀 Triple Pendulum API  
Backend for Triple Pendulum Simulation (NestJS + Prisma + Python)

The **Triple Pendulum API** is a backend service built with **NestJS**, **Prisma**, and a **Python simulation engine** that computes the motion of a chaotic triple pendulum using Lagrangian mechanics.  
It exposes REST endpoints for:

- Running new simulations  
- Fetching existing results  
- Storing GIF animations generated by Python  
- Managing users and their simulation histories  

This backend powers the **triple-pendulum-frontend** React/Vite application.

---

## 🚀 Features

### 🔧 Core Simulation Logic
- Executes triple-pendulum dynamic simulations using Python (SciPy/NumPy).
- Generates animation GIFs automatically.
- Caches results to avoid recomputing identical initial conditions.

### 🗄️ Database (Prisma + PostgreSQL)
- Stores simulations in the `Result` model.
- Tracks:
  - `theta1_init`, `theta2_init`, `theta3_init`
  - `gifPath`
  - timestamps
  - user associations (optional)

### 🌉 REST Endpoints (NestJS)
- `POST /v1/users/simulate` — run a simulation or return a cached one
- `GET /results` — list all results
- `GET /results/:id` — get a single result
- `PATCH /results/:id` — update
- `DELETE /results/:id` — delete

### 🐍 Python Integration
- Uses `python-runner.ts` to:
  - call Python
  - compute the simulation
  - save `result.json` and `pendulum.gif`
  - return the generated paths to the API
